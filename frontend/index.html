How to read this

Physical network groups use DFS to group nodes connected by active pipes; pipe direction is ignored because this model treats a pipeline as traversable in either direction. These groups are not supply routes. Tank routes use Dijkstra to show the lowest-distance path over active pipes. Failed pipes are excluded. AquaGrid calculates network paths, not real water pressure or flow rate.
